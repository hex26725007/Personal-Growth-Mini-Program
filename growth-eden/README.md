# 个人成长进化乐园 · 微信小程序 MVP

一个用「每日小任务 → 成长值 → 等级 / 六维能力 / 徽章」驱动个人成长的小程序 MVP，可直接导入微信开发者工具做真机测试。

---

## 一、快速开始

1. 微信开发者工具 → 导入项目 → 选择本目录（`growth-eden`）
2. `project.config.json` 里的 `appid` 改成你自己的小程序 AppID（测试号/游客模式不支持云开发）
3. 直接编译即可运行：**未配置云环境时会自动降级为本地存储，功能完整**
4. 需要云端同步时：
   - 工具栏「云开发」→ 开通并创建环境，复制环境 ID
   - 填到 `miniprogram/config/env.js` 的 `CLOUD_ENV_ID`
   - 右键 `cloudfunctions/growth` → 上传并部署（云端安装依赖）
   - 云数据库会自动创建 `growth_users` 集合（也可手动创建，权限设为「仅创建者可读写」）

> 演示数据：新用户默认是 Lv.3、本周成长值约 45%、已完成 34 个任务、解锁 4 枚徽章，方便测试用户一进来就有内容可看。「我的 → 重置为示例数据」可随时恢复。

## 三、核心机制（MVP 口径）

| 机制 | 规则 |
| --- | --- |
| 成长值 | 每个任务 8–25 点，完成即入账，记在「本周成长值」和「累计成长值」 |
| 等级 | 本周成长值每满 500 升 1 级，超出部分滚入下一级，周一重置本周进度 |
| 六维能力 | 学习 / 专注 / 健康 / 情绪 / 行动 / 社交；每项 0–100 经验，满 100 升 1 级（上限 Lv.10） |
| 每日任务 | 每天 0 点按日期种子从任务库生成 5 个任务，六维各覆盖 1 项，同一天不会变；可「换一批」 |
| 连续天数 | 当天完成首个任务 +1；断签归零；用于连胜类徽章 |
| 徽章 | 12 枚，条件全部由代码判定（见 `utils/data.js` 的 `BADGES`），满足即自动解锁 |
| 数据 | 本地 Storage 是真相源，云开发开启后 900ms 防抖异步同步；启动时取较新的一份 |

## 四、给真实用户测试时建议关注

1. 打开小程序后，是否 10 秒内明白「我该点哪里」——首页的今日待办是否够显眼
2. 完成任务时的 +成长值 / 升级 / 解锁徽章反馈，是否让人想再来一次
3. 能力树的六维是否看得懂、是否愿意点开某个能力看训练建议
4. 徽章墙的「未解锁」是否构成目标感，还是会劝退
5. 是否会在第二天主动回来（连续天数 + 提醒时间是关键）

建议配一份 3–5 人的可用性测试脚本：让用户完成「今天的第一个任务」，观察他是否需要提示。
